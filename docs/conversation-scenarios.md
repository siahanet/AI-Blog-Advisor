# Example Conversation Scenarios

## Scenario A: User Has No Idea
1. Assistant welcomes user in Arabic.
2. User says they are unsure.
3. Assistant generates niche paths.
4. User chooses one path.
5. Assistant analyzes and refines.
6. Assistant proposes monetization mix and 30-day content plan.
7. Assistant gives readiness score + next actions.

## Scenario B: User Has Broad Idea
1. User: "I want a tech blog."
2. Assistant analyzes weakness (too broad).
3. Assistant narrows to audience + pain point.
4. Assistant compares monetization models and trade-offs.
5. Assistant provides startup checklist.

## Scenario C: Weak/Risky Idea
1. User idea has low monetization signal.
2. Assistant acknowledges and explains risks.
3. Assistant suggests stronger adjacent niches.
4. Assistant lets user choose between improving or pivoting.
